# 🐼 판다 탐험대 - 대나무 언덕 (1차시: 니하오! 중국어와 첫 만남)

초등학교 3~4학년 대상 실시간 중국어 수업용 대화형 학습 게임입니다.
설치나 로그인 없이 바로 열어서 사용할 수 있습니다.

## 폴더 구성
```
panda-chinese-game/
├── index.html     ← 이 파일을 브라우저로 열면 게임이 시작됩니다
├── styles.css      디자인
├── game.js         게임 내용(대사·퀴즈)과 로직
├── assets/
│   ├── panda_hero.png    판다 주인공 '판디'
│   ├── teacher_npc.png   선생님 NPC
│   ├── friend_npc.png    친구 NPC
│   └── bamboo_hill.png   배경(대나무 언덕)
└── README.md
```

## 가장 쉬운 사용 방법 (설치 없이)
`index.html` 파일을 더블클릭하면 기본 브라우저(크롬 등)에서 바로 열립니다.
개인 컴퓨터에서 혼자 테스트할 때는 이 방법으로 충분합니다.

⚠️ 다만 일부 브라우저는 `파일을 더블클릭해서 열 때(file://)` 이미지가
간혹 안 보일 수 있습니다. 그럴 땐 아래 "수업 중 공유용" 방법을 사용해 주세요.

## 수업 중 학생들과 함께 쓰는 방법 (추천)
가장 간단한 방법은 무료 정적 호스팅 사이트에 이 폴더를 그대로 올리는 것입니다.
코딩 지식이 없어도 아래처럼 드래그 앤 드롭만 하면 됩니다.

1. https://app.netlify.com/drop 접속
2. `panda-chinese-game` 폴더 전체를 그 화면에 끌어다 놓기
3. 몇 초 뒤 생기는 링크(예: `https://xxxx.netlify.app`)를 학생들에게 공유
   (화상수업 화면공유로 직접 보여줘도 되고, 학생이 각자 자기 화면에서 열어도 됩니다)

GitHub Pages를 쓰신다면 이 폴더를 그대로 저장소에 올리고 Pages 기능을 켜시면 됩니다.

## 진행 방식
타이틀 → 판디와 선생님 만남 → 你好 → 老师好 → 同学们好/你们好 →
中国/汉语 → 성조 체험(妈/麻/马/骂) → 최종 복습 퀴즈(4문항) → 결과 화면

- 모든 단계는 "대사 보기 → 중국어 듣기(🔊) → 선택지 고르기 → 피드백 → 따라 말하기 유도" 흐름입니다.
- 오답을 골라도 게임이 끝나지 않고, 다시 고를 수 있습니다.
- 정답을 맞히면 별(⭐)을 얻습니다.
- 오른쪽 위 "📒 배운 표현" 버튼을 누르면 지금까지 배운 단어를 언제든 다시 듣고 복습할 수 있습니다.
- 진행 상황은 브라우저에 자동 저장됩니다(새로고침해도 이어서 진행됩니다). 서버·회원가입은 없습니다.

## 발음 듣기(🔊) 안내
브라우저 내장 음성 합성 기능(Web Speech API)을 사용합니다.
크롬 브라우저 + 인터넷 연결 상태에서 가장 안정적으로 동작합니다.
기기나 브라우저에 따라 중국어 음성이 지원되지 않을 수 있으며,
이 경우 소리 없이 넘어갈 뿐 게임 진행에는 지장이 없습니다.
(추후 실제 녹음 음성 파일로 교체하는 것도 가능합니다.)
