# 프로젝트: 판다 탐험대 - 대나무 언덕 (1차시)

초등학교 3~4학년 대상 **실시간 온라인 중국어 수업**에서 5~10분씩 쓰는 대화형(비주얼노벨 스타일) 학습 게임.
제작자는 코딩 초보자이므로 설명은 쉬운 한국어로, 수정 전에 무엇을 바꿀지 먼저 알려줄 것.

## 목표
- 재미보다 **듣고 → 보고 → 고르고 → 따라 말하는** 학습 경험이 우선.
- 한 장면은 20~40초 안에, 클릭 2~3번 안에 학생이 선택하거나 참여하게 한다. 긴 설명문 금지.
- 분위기는 밝고 귀여운 2D 판타지 탐험. 특정 게임(메이플스토리 등)의 캐릭터·맵·UI를 그대로 복제하지 않는다.
- 회원가입, 서버, 로그인 없이 바로 플레이. 진행 상황은 브라우저 localStorage에만 저장.

## 파일 구조
- `index.html`: 화면 뼈대 (타이틀 / 대화·퀴즈 공통 화면 / 결과 화면 / 학습카드 모달)
- `styles.css`: 모든 디자인. 색상은 상단 `:root` 변수로 관리
- `game.js`: 게임 로직 + 대본
  - `VOCAB`: 단어(한자, 병음, 뜻)
  - `SPEAKERS`: 등장인물(이름, 이미지, 좌우 위치)
  - `STEPS`: 1차시 진행 순서. type은 `dialogue`(대사) / `choice`(선택형 퀴즈) / `tone`(성조 체험) / `result`(결과)
- `assets/`: `panda_hero.png`(판디), `teacher_npc.png`(리리 선생님), `friend_npc.png`(메이), `bamboo_hill.png`(배경)

## 수정 방법 요약
- 대사·퀴즈 바꾸기: `game.js`의 `STEPS` 배열만 수정.
- 새 단어 추가: `VOCAB`에 항목 추가 후 `STEPS`에서 `vocab: "키"`로 연결.
- 새 인물 추가: `SPEAKERS`에 항목 추가, 이미지는 `assets/`에 넣기.
- 새 차시(예: 2차시) 추가: 같은 구조로 `STEPS`와 `VOCAB`을 별도 세트로 만들고, 배경 이미지를 교체. 저장 키 `SAVE_KEY`를 차시별로 다르게 할 것.
- 이미지는 비율을 늘이거나 찌그러뜨리지 말 것. 캐릭터가 학습 텍스트를 가리지 않게 할 것.

## 현재 상태 (정직한 기록)
- 직접 확인함: 모바일(430px)·PC(1280px) 화면 렌더링, 처음부터 결과 화면까지 전체 진행, 정답 시 별 증가, 새로고침 후 이어하기, 학습카드 모달.
- 확인 못 함: 실제 스마트폰·태블릿 실기기 터치, 기기별 중국어 음성(TTS) 품질, 여러 학생 동시 사용.
- 구현 안 됨: 마이크 음성 인식, 실제 녹음 음성 파일, 효과음, 학생별 성적 저장, 2~12차시.
- 오답 시 다시 시도할 수 있고 게임오버는 없다. 별(⭐)은 정답마다 1개씩 지급한다.

## 작업 원칙
- 잘 되는 기능을 함부로 지우지 말고 기존 코드를 최대한 재사용한다.
- 구조를 크게 바꾸기 전에 어떤 파일을 어떻게 바꿀지 먼저 설명한다.
- 테스트하지 않은 것을 테스트했다고, 구현하지 않은 것을 구현했다고 말하지 않는다.
- 작업 후에는 수정한 파일, 새로 만든 파일, 직접 테스트한 것, 테스트 못 한 것을 나눠서 보고한다.
