# 프로젝트: 판다 탐험대 출동! (중국어 숫자 1~10 탐험 게임, 초기 시안)

초등학교 3~4학년용. 판다 '판디'가 작은 마을을 돌아다니며 NPC 10명의 부탁(사과 1개, 귤 2개 ...)을 해결하고 중국어 숫자 카드(一~十)를 모으는 게임.
원래 기획은 `기획서.txt`에 있다. 제작자는 코딩 초보자이므로 설명은 쉬운 한국어로 할 것.

## 파일
- `panda-numbers-game.jsx`: React 컴포넌트 1개(기본 export `PandaNumberGame`)가 게임 전체. Tailwind 클래스 사용, 외부 라이브러리 없음.
- `기획서.txt`: 원본 게임 기획서(학습 목표, 10개 미션, 카드 시스템, 확장 아이디어)

## 구조 요약
- `NUMBERS` 배열: 숫자 10개의 한자·병음·NPC·아이템·대사·맵 좌표
- 화면 3개: 타이틀 → 맵(방향키 이동, NPC에서 대화) → 엔딩
- 미션: 목표 개수만큼 아이템을 골라 확인. 틀려도 게임오버 없이 재시도
- 정답 시 한자·병음·개수 카드 + 🔊 발음(브라우저 TTS), 하단 10칸 카드 트레이로 복습

## 실행하는 법
- claude.ai 채팅에서: 이 `.jsx` 파일을 첨부하고 "이 React 코드를 아티팩트로 실행해줘"라고 요청.
- 자기 프로젝트에서: React + Tailwind CSS 환경에 파일을 넣고 import해서 렌더링.

## 현재 상태 (정직한 기록)
- 이 파일은 Claude 채팅에서 아티팩트로 작성되었고, 코드 작성 환경에서 직접 렌더링·실행 테스트는 하지 않았다. 동작을 확인하려면 먼저 실행해 볼 것.
- 이모지(🐼🍎 등)로만 그린 시안이라 이미지 에셋은 없다.
- 이후 수업용으로 방향이 바뀌어(방향키 이동 → 대화형 비주얼노벨) **`1-panda-chinese-game`이 메인 프로젝트**다. 이 게임은 숫자 차시 소재로 재활용하는 것을 권장한다.
  - 재사용하기 좋은 부분: 숫자 카드 트레이, 오답 시 격려 피드백, 🔊 발음 함수, 숫자 ↔ 개수 ↔ 한자 ↔ 병음 연결 방식

## 작업 원칙
- 잘 되는 기능을 함부로 지우지 말고, 구조를 크게 바꾸기 전에 어떤 파일을 어떻게 바꿀지 먼저 설명한다.
- 테스트하지 않은 것을 테스트했다고, 구현하지 않은 것을 구현했다고 말하지 않는다.
